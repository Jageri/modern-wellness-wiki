# 现代养生百科

[English](README_en.md)

![Modern Wellness Wiki](assets/cover.jpg)

面向普通读者的中英文健康与长寿知识库，围绕日常选择解释研究发现、适用范围和不确定性。

## 先找到与你有关的决定

先看适用人群和“做”，再查看证据及局限。可以从这些问题进入：

- 日常习惯怎么调整：[步行](wiki_zh/动/日常/-17%25%20步行.md)、[力量训练](wiki_zh/动/-15%25%20力量训练.md)、[睡眠不足](wiki_zh/睡/~%20睡眠不足.md)。
- 已有风险怎么处理：[吸烟](wiki_zh/医/+100~300%25%20吸烟.md)、[高血压](wiki_zh/医/~%20高血压（未控制）.md)、[高胆固醇](wiki_zh/医/~%20高胆固醇.md)。
- 检查或补剂值不值得：[癌症筛查](wiki_zh/医/~%20癌症筛查.md)、[保健品识别方法](wiki_zh/吃/补剂/~%20保健品识别方法.md)。

## 浏览与理解条目

[全量索引](INDEX.md)提供中文条目导航，网站侧栏可按主题浏览中英文内容。读条目时同时查看结论、适用人群、行动建议及参考来源。

文件名中的百分比不是跨条目收益排名。符号含义见[文件命名规则](docs/standards/条目撰写标准.md#文件命名)，星级含义见[证据评级规范](docs/standards/证据评级规范.md)。
