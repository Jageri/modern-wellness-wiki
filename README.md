## 浏览与理解条目

- **想查一个具体问题**：在[网站](https://jageri.github.io/modern-wellness-wiki/)使用搜索框；侧栏按主题浏览，手机上可展开菜单。
- **想看条目的简短介绍**：打开[全量表格索引](INDEX.md)，同时查看研究涉及的影响与分类。
- **想判断结论是否适合自己**：把结论、适用人群、行动建议、证据局限和参考来源一起看。
- **想追溯更新和核验**：网站各条目底部提供审阅日期、原始审计记录与中英文切换；也可查看[复审状态](https://jageri.github.io/modern-wellness-wiki/docs/tracking/复审状态)。

文件名中的百分比不是跨条目收益排名。符号含义见[文件命名规则](docs/standards/条目撰写标准.md#文件命名)，星级含义见[证据评级规范](docs/standards/证据评级规范.md)。
