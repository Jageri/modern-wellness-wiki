## 主要问题与优先级

### P1：公开阅读入口仍在传播已被正文撤销的判断

`README.md:55–61` 鼓励按死亡率数字排序，并将“−47% 挥拍运动”标为“收益最大”；`README_en.md:60` 同样写为 Most beneficial。公开 README 的 HTTP 响应仍包含该例子。

与之对应，现有 `wiki_zh/动/有氧/~ 挥拍运动.md:3–16` 明确没有可泛化的单一效应值，不能证明其普遍优于其他运动。因此这不是文字润色，而是入口与正文相互矛盾。跨研究的相对风险还混合了不同人群、对照和暴露，不能直接作为干预排行榜。

建议同步改写双语 README 与索引说明，将读者导航改为“证据确定性、适用人群、行动优先级”；研究数字可留在正文，并显示比较对象。12 个保留数字前缀不因本次评估自动判错，但不应用于跨条目排序。

### P1：星级规范含义不一致

`docs/standards/条目撰写标准.md:31` 将 Meta 分析/大型 RCT 归为五星；`docs/standards/条目权威性审计标准.md:219–223` 又把五星定义为多项 RCT 一致、两星定义为研究矛盾。这两套口径不能稳定地产生同一评级。

建议评级对应具体问题和终点，区分研究设计、证据确定性和行动建议强度。不能仅凭“Meta 分析”名称给最高等级，也不宜用一颗总星级同时代表症状改善和死亡结局。

### P2：葡萄糖胺遗漏直接的死亡阴性队列

本次额外找到并核验 Bhimani 等 2023 年 NHANES 研究：38,021 名成人，多变量调整后葡萄糖胺与全因死亡无显著关联，HR 1.02（95% CI 0.86–1.21）。[原始记录](https://pubmed.ncbi.nlm.nih.gov/36971848/)

现有中英文葡萄糖胺条目均未引用该研究。已有方法学反证和“不为延寿服用”的结论是合理的；新增阴性队列不会推翻这个结论，但能补足直接终点证据平衡。不能把这一个发现外推为全库遗漏率。

### P2：正文引用对应仍不统一

17 篇中文正文在参考文献段之前没有数字引用编号、Markdown 脚注或直接 URL。部分段落用作者、年份或研究名称帮助对应，所以这不代表这些主张全部无来源；但缺少统一、明确的引用对应，也增加读者逐项复核的成本。

确认的 17 篇：空气污染、冷水澡、CVD 泡澡、体温调节、芬兰式干桑拿、多巴胺管理、压力管理、抑郁、刷牙、超加工食品、油炸食品、红肉过量、白肉、NMN 与 NAD+、鱼油、复合维生素、午睡。

建议优先给核心数字和行动建议添加明确的引用锚点，再统一参考文献格式。

### P2：缺少内容与 PR 自动检查

`.github/workflows/deploy-pages.yml` 仅在推送 main 和手动触发时运行构建与 SEO 检查；没有 `pull_request` 触发。`scripts/check-site-seo.mjs` 检查元数据、页面数量和语言映射，没有核对正文引用集合、INDEX 与正文一致性、审计状态或复审到期。

检查器硬编码 200 篇与 100 对，新条目增加时还需要手动同步；双语配对通过共同引用推断，缺少稳定条目 ID。

建议建立一个小型内容清单，包含稳定 ID、双语路径、证据复核日期与审计路径，并在 PR 阶段检查引用集合、必填字段、索引目标及待核验状态。语义和医学判断仍需要人工或专门审阅，不能用结构检查代替。

### P2：维护信息与当前内容脱节

`docs/tracking/待完善条目清单.md:3` 仍以 v1.0、76 条作为“当前进展”，并被首页当作现行待办入口。阿司匹林一级预防、轮班/节律紊乱、更年期和整体膳食模式仍没有独立条目；他汀、DASH、地中海饮食等已有部分内容散落在相关条目，不能简单算作完全缺失。

生成页面的“审阅与纠错”只展示 Git 修改日期并链接通用规范（`scripts/prepare-site.mjs:102–106`），没有直达本条审计、证据检索截止日期或下次复审日期。现有全库总结明确记录由 agent 审计，不能将其等同于外部医学专家署名复核。

建议先更新待办状态和页面复审元数据，再按真实读者需求补内容；条目数量本身不等于覆盖率。本次未重新计算历史宣称的 90–97% 覆盖率。

### P2：构建依赖存在安全公告

`npm audit --json` 返回 3 个受影响包：2 个 moderate、1 个 high，沿 esbuild → Vite → VitePress 依赖链传播，不是三个独立的线上漏洞。

高等级项涉及 Windows 特定文件路径与暴露到网络的 Vite 开发服务器。[官方公告](https://github.com/advisories/GHSA-fx2h-pf6j-xcff)。当前为 macOS 本地环境、GitHub Pages 静态发布，因此没有证据表明线上静态页面受到同样影响。应安排兼容升级和回归验证；本次未改依赖，也未运行自动修复。
