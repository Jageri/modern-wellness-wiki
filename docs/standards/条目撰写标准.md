# 条目撰写标准

每个条目必须满足以下全部条件，否则标记为"⚠️ 待完善"。

---

## 选题范围（2026-08-05 修订）

**收录主线**：一切与全因死亡率 / 预期寿命 / 重大健康风险（事故、急症、可预防疾病）有可追溯证据关联、且**个人可干预**的话题。不局限于医疗健康——衣、食、住、行、动、睡、心、形、医、财等领域均在范围内。

- 生活领域示例：驾驶疲劳、高温防护、食品安全、居住与环境暴露、家庭应急准备等。
- 财富/保障类话题（保险、社会经济地位、财务安全）同样收录，依据：财富与寿命的关联有大型队列研究支撑（如 JAMA 2019 财富-预期寿命梯度研究）。
- 不收录：纯公共卫生层面、个人无法干预的因素。

**条目分两级**：

| 级别 | 定义 | 文件名前缀 |
|------|------|-----------|
| 核心条目 | 有全因死亡率/寿命数据 | 具体数字，如 `-15%`、`+20~30%` |
| 指南条目 | 无 ACM 数据，但有高质量证据的重大健康风险/急救/就医导航/生活保障类 | 统一用 `~` |

**前缀约定**：今后不确定/无数据前缀一律用 `~`（存量条目中的 `≈ ? ∝` 不改名，逐步自然淘汰）。

---

## 字段结构

| 字段 | 要求 |
|------|------|
| 死亡率影响 | 必填。具体数字 + 来源（如"+30%全因死亡风险，BMJ 2024 Meta分析"） |
| 证据等级 | 必填。⭐⭐⭐⭐⭐ Meta分析/大型RCT / ⭐⭐⭐⭐ 多项研究一致 / ⭐⭐⭐ 单项大型研究 / ⭐⭐ 小样本 / ⭐ 专家意见 |
| 结论 | 必填。1-2句话，直接给答案 |
| 证据 | 必填。至少1条，附原文URL |
| 做 | 必填。至少3条可操作建议 |
| 不做 | 至少2条常见误区（如无可靠来源支撑，不要硬凑）|
| 就医信号 | 至少2条（如无可靠来源支撑，不要硬凑）|
| 参考文献 | 必填。按照论文格式，在正文中标注引用符号[1][2]等，并在文末按论文格式列出文献及其线上链接 |

## 来源要求

- 优先：Lancet / BMJ / NEJM / JAMA / Nature / WHO / CDC，其他权威机构发布也可
- 每条核心数据必须附原文URL
- 无来源的结论标注"⚠️ 待验证"或删除
- 不接受"多项研究表明"这种模糊表述——必须指明是哪项研究
