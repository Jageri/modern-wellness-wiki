# 条目撰写标准

更新于 2026-09-26。本页负责收录范围、命名、字段与引用呈现；其他规则见[文档分工](../README.md)。

## 选题范围

收录与全因死亡率、寿命或重大健康风险有可追溯证据关联，且个人可采取行动的话题。范围覆盖生活方式、环境、身体与心理健康、医疗、居家安全、出行和生活保障。

有直接死亡或寿命证据的主题可作为核心条目；缺少这类终点、但有可靠健康风险或指南依据的主题也可收录。纯政策层面且没有个人行动空间的因素不单独成条。先按[完整性审计标准](条目完整性审计标准.md)检查现有覆盖，避免同义或范围重叠的条目。

## 文件命名

- 路径沿用对应语言的实际分类目录，文件名为“前缀 + 空格 + 主题名”。
- 数字前缀只能摘要与该主题、暴露和比较对象直接对应的全因死亡或寿命结果。正文开头必须说明研究人群、比较对象和研究设计；观察性关联不能写成干预的因果获益。
- 没有适合概括条目的统一死亡数字时用 `~`：包括证据缺失、结果不一致、主要讨论其他终点或指南行动。`~` 不等于无效。
- 不使用 `≈`、`?`、`∝` 作为替代前缀；不把发病率、替代终点、跨疾病比较或动物机制的数字当成死亡效应。
- 不同条目的百分比不能直接比较、相加或用于预测个人结果。

## 字段与引用

可使用适合读者的同义标题，但以下信息必须清楚可见：

| 内容 | 要求 |
| --- | --- |
| 死亡率影响 | 给出有来源的限定结果，或明确缺少可用数字；不强行填百分比 |
| 证据等级 | 使用[证据评级规范](证据评级规范.md) |
| 可操作性 | 说明个人可以采取的行动及适用边界 |
| 结论 | 先回答读者的问题，再说明关键不确定性 |
| 证据 | 交代支撑结论的研究、比较对象、终点及局限 |
| 做 | 给出有来源支持、可执行的建议；不为凑数量补写无依据内容 |
| 不做、就医信号 | 主题适用且有依据时提供，不机械套入每篇 |
| 参考来源 | 核心数字、结论及行动建议均有明确对应；列出文献或权威原始来源及链接 |

引用可用编号、Markdown 脚注或段内来源链接。文献至少注明题名、作者或机构、发表年份和来源；有 PMID 时同时提供 PubMed 链接，非论文指南链接至发布机构。不要只写“多项研究表明”。

来源是否可靠、数字是否相符、反面证据是否充分，按[权威性审计标准](条目权威性审计标准.md)核验。未解决的关键引用问题应留在审计记录中，不能靠正文占位标记当作完成。
