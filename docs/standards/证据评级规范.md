# 证据评级规范

本页是撰写与审计共同使用的评级口径，更新于 2026-09-26。星级是本站的阅读提示，不是正式 GRADE 评级，也不是行动推荐强度或效果大小。

## 先说明在评价什么

星级旁必须写明问题：特定人群中某项干预对死亡、疾病、症状或功能的作用，或某项暴露与死亡的关联。一个条目涉及多种终点时，在正文分别解释；症状改善的证据不能提升“延寿”的确定性。

| 星级 | 含义 | 判断要求 |
|---|---|---|
| ⭐⭐⭐⭐⭐ | 对明确问题有高确定性的直接证据 | 多项低偏倚、充分检验功效、结果一致的直接研究支持；须交代效应大小和适用范围，不能写“绝对确凿” |
| ⭐⭐⭐⭐ | 对明确问题有较强证据，仍有重要边界 | 多项研究或较可靠的大型研究支持；若来自观察性队列，评级只能表示关联较稳定，必须同时写明因果未确立 |
| ⭐⭐⭐ | 初步或有限证据 | 单项大型研究、有限复现，或存在明显异质性、间接性及人群限制 |
| ⭐⭐ | 证据薄弱或不一致 | 小样本、短随访、偏倚较大、结果相互矛盾，尚不能形成稳定结论 |
| ⭐ | 对所问的人体临床结局没有可靠直接证据 | 仅机制、动物、专家意见，或干预尚未清楚定义；明确人体证据缺口 |

## 共同规则

- Meta 分析不是自动五星。先检查纳入研究的设计、偏倚、异质性、样本量和终点；低质量观察性研究汇总后不会自动变成因果证据。
- 阴性结果可以有高质量证据，但“未达统计学显著”不自动等于“已证明无效”。结合置信区间和检验功效解释。
- 若来源使用 GRADE，保留来源对具体结局的评级，写明与本站星级的区别；不得改写为更高确定性。
- 行动建议另行考虑绝对收益、风险、负担、成本、个人偏好及指南适用人群。没有延寿证据不代表没有症状、功能或安全价值。
- 新增或修改星级时，记录所评问题、依据、降级理由，并同步中英文。已有条目不因本规范发布自动完成重新评级，后续实质复审仍需逐条留痕。
