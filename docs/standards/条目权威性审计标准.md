# 条目权威性审计标准

更新于 2026-09-26。本页负责来源核验、审计维度、判定与记录；条目格式、评级和复审安排分别见[文档分工](../README.md)。

## 原始来源核验

每个实质性结论与核心数字都必须有真实、可核对的来源；不能编造引用或数据，也不能将一篇论文的数据归于另一篇。至少有一项可验证的参考来源才能形成条目。

1. 提取拟保留的结论、样本量、效果量、置信区间、比较对象及引用。
2. 围绕研究问题检索支持证据、阴性或相反证据及近期更新。按与问题的直接相关性和方法质量筛选，不按引用量、期刊名或固定“Top 10”数量代替判断。
3. 打开 PubMed、出版社或原发布机构的记录，核对题名、作者、期刊或机构、年份和 PMID；数字还需定位到支持该主张的摘要段落、正文或表格。搜索摘要和模型记忆不能作为通过依据。
4. 普通 PubMed 页面不可用时，可使用同一 PMID 的 NCBI 原始记录接口，并记录替代路径。无法核验的内容明确列为未解决项，不能记作通过。
5. 按下表审阅两种语言，修正后确认主张、数字、限定语与引用对应一致。引用呈现格式遵循[撰写标准](条目撰写标准.md#字段与引用)，星级遵循[评级规范](证据评级规范.md)。

## 十项审计维度

| 维度 | 检查内容与修正依据 |
| --- | --- |
| 来源质量 | 研究是否直接回答该问题；检查设计、偏倚和可复现性，不能仅凭大型 RCT 或 Meta 分析名称判定可靠。预印本、会议摘要等未完成同行评审的材料只能在明确披露时作为线索，不能承担确定性健康结论；排除虚假或掠夺性来源 |
| 结论一致性 | 结论是否忠于原始结果与整体证据；不能把探索性、亚组或不显著结果写成确立的获益 |
| 反面证据 | 是否主动查找并呈现直接相关的阴性、相反或方法学反证；解释分歧而非只选支持方 |
| 效果量准确性 | 逐项核对数字、单位、随访期与终点；区分相对变化和绝对百分点，给出可获得的基线风险。比值的无效线为 1，差值为 0；结合区间与检验功效解释不确定性 |
| 利益冲突 | 核对资金来源、作者财务关联与独立复现；未知则说明未能核验，不直接记“无利益冲突” |
| 因果与相关 | 观察性关联不能自动解释为干预效果；检查混杂、选择偏倚和因果推断依据，并按撰写标准审查数字前缀 |
| 人群适用性 | 交代年龄、性别、地区与健康状态；不把特定患者、剂量或制剂结果无条件推广到普通人或其他产品 |
| 研究局限性 | 说明会改变结论的样本量、随访、暴露测量、失访、偏倚或间接性；替代终点、动物和机制证据与人体临床结局分开 |
| 发表偏倚 | 检查注册结果、未发表阴性结果及综述的相关评估；漏斗图或相关检验不足以排除偏倚时保留限制 |
| 时效性 | 查找会改变判断的新研究、指南、勘误和撤稿；旧研究可保留，但不能忽略实质更新，也不按发表年份机械替换 |

## 判定与记录

核心来源未核实、关键数字不符或结论越过证据边界时，结果记为“需修正”，不得把已运行检查等同于内容通过。修正完成后复核，区分“通过”和“修正后通过”；仍存在的合理不确定性写入正文。局部抽查必须注明具体范围，不能外推为整篇或全库重新审计。

每条实质审计使用有日期的目录，批量任务可按稳定 ID 设子目录。目录放在 `audits/` 下，包含：

| 文件 | 内容 |
| --- | --- |
| `AUDIT.md` | 日期、范围、审阅者及类型、判定；逐项检查结果和对应 URL；问题、修正与剩余限制 |
| `PMID_VERIFICATION.md` | 每个核验 PMID 的原始 URL、获取方式、题名/作者/年份匹配情况、所用数字的定位、结果、核验者和日期；失败也记录 |
| `HANDOFF.md` | 实际修改的双语文件、验证结果、未解决项及提交/发布状态 |

批量审计可另存进度和总结；已有档案保留原结构，不为统一格式重写历史结论。新记录中引用非 PubMed 来源时，同样写明原始 URL、核验位置与结果。

复审周期、清单状态和提交前检查统一按[维护说明](../tracking/维护说明.md)执行。
