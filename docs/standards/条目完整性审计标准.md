# 条目完整性审计标准

更新于 2026-09-26。本页定义如何识别内容缺口，不维护某次盘点的条目总数、风险排行榜或待写任务。

## 确定比较范围

每轮盘点先写明目标人群、地域、健康问题、证据截止日期和仓库基线。收录边界按[条目撰写标准](条目撰写标准.md#选题范围)，当前条目以 `docs/tracking/entries.json` 及实际双语正文为准。

可从疾病负担研究、公共机构指南和读者常见决策建立候选主题。使用 GBD、WHO、CDC 等材料时，记录实际查阅的版本、发布日期、指标和原始 URL，不能把某年的数字固定写入本规范。书籍、播客、商业网站和其他知识库可提供选题线索，其目录或流行度不等于医学证据。

## 逐项比对

对候选主题检索同义词并阅读现有正文，而不只比较文件名。记录以下一种状态：

| 状态 | 判断 | 后续处理 |
| --- | --- | --- |
| 已覆盖 | 相关人群、主要问题、关键证据与行动已覆盖 | 记录对应条目 |
| 部分覆盖 | 有相关段落，但存在明确问题或人群缺口 | 优先扩写，确需独立阅读时再拆分 |
| 未覆盖 | 库内没有足以回答该问题的内容 | 列入候选，另做证据审计后决定收录 |
| 范围外 | 不符合收录边界，或只是现有主题的别名 | 记录理由，不重复开条 |

主题相近不代表可互相替代，例如食物与补剂、症状与疾病、全因死亡与某一病因死亡应分别判断。优先级结合读者需求、风险、可采取的行动和与现有条目的互补程度，不按跨研究死亡百分比排序。

## 记录与输出

每轮结果存入 `audits/完整性审计记录/` 的有日期报告，包含仓库基线、参考来源、候选主题、对应条目、覆盖状态、判定理由与下一步。待执行事项集中更新[待完善清单](../tracking/待完善条目清单.md)，不再另建一份“当前任务”列表。

若报告覆盖率，必须公开分母、去重方式、排除项和“部分覆盖”的计分方法。不能仅凭条目数量、来源数量或不同范围的历史百分比宣称完整。
